How to get your free ElevenLabs Key:

  1. Log in to elevenlabs.io
  2. Click your profile icon at the bottom-left and select API Keys
  3. Click Create API Key, copy it, and paste it into the box above
  4. Important: Make sure Text to Speech and Voices are enabled in key permissions.
